## 음악 반복과 성능 보완

원본 배경음악 ON/OFF 안내는 브라우저 설정과 중복되므로 화면 안내에서 제외했습니다. 원본 음악 사건은 하나의 반복 재생 채널로 연결하며, 재생 중인 음악을 새로 시작하지 않습니다. 음소거는 재생 중인 모든 소리를 정지하고 음량 변경도 저장합니다. 자동 재생이 거절되면 사건마다 재시도하지 않습니다. 효과음은 파일별 최대 2개, 동시 최대 8개이며 같은 순간의 중복 요청을 걸러냅니다.

원본 조건 검색은 소유자와 유닛 종류별 검색 결과를 재사용합니다. 소유권 이전과 유닛 이동 시 캐시를 비우며, 여러 소유자의 유닛을 조회할 때는 원본 순서를 유지합니다. 지형은 화면에 보이는 영역만 그립니다.

동일 난수 조건의 60초 모의 실행에서 변경 전후 전체 원본 유닛 상태, 플레이어 상태와 사건 저장 상태가 일치했습니다. 측정 환경의 실행 시간은 최종 비교 실행에서 11,193ms에서 10,565ms로 감소했습니다. 실행 시간은 측정 시점의 시스템 부하에 따라 달라집니다. 실제 기기 FPS나 음악 청취 검증을 의미하지 않습니다. `node test-audio.cjs`는 오디오 모형으로 반복 재생, 음소거, 음량 저장과 자동 재생 거절을 검사합니다.

## 패치 6: 사건 분류, 보스 전투와 점령

원본 CHK의 분류 번호를 None 228, Any Unit 229, Men 230, Buildings 231, Factories 232로 바로잡았습니다. 기존 코드의 분류 오류 때문에 병력의 지역 진입과 건물 소유권 이전 조건이 잘못 평가됐습니다. 출처: BWAPI UnitType.h (https://github.com/bwapi/bwapi/blob/main/bwapi/include/BWAPI/UnitType.h).

원본 점령 사건 52개를 찾아 플레이어의 점령 요청과 연결했습니다. 수비 병력, 방어탑, 지역과 관련 사건 조건을 통과해야 시작하며, 4초간 유지한 다음 원본 행동으로 소유권을 이전합니다. 이동이나 피해는 점령을 취소합니다. 점령 결과는 원본 유닛 상태에 저장됩니다. 건물은 외곽 기준으로 기본 공격하며, 모바일에서도 짧게 눌러 공격 대상을 선택할 수 있습니다.

보스 16종에 각 2개의 브라우저판 전투 기술을 연결했습니다. 돌진, 직선 공격, 범위 공격, 소환, 회복, 보호와 흡혈을 조합하며 경고 범위, 준비 시간, 개별 재사용 시간과 체력 절반 이하의 강화를 적용합니다. 원작 기술을 그대로 재현했다는 의미는 아닙니다. 임무 화면의 보스 기술 안내에서 패턴을 확인할 수 있습니다. 화면 바깥 오른쪽에 배치된 보스도 표시합니다.

음악 ON/OFF 안내는 문자열 번호뿐 아니라 내용으로도 차단하고, 과거 사건 기록에서도 표시하지 않습니다. 실제 음악 설정은 브라우저 설정의 단일 재생기를 사용합니다.

검증: 원본 사건 3,009개의 조건 9,255개와 활성 행동 27,670개를 각각 실행해 호환성을 검사했습니다. 이것은 전체 이야기의 자연스러운 순서와 모든 엔딩을 실제로 완주했다는 의미가 아닙니다. 보스 기술 32개와 점령 소유권 이전, 저장 복원 및 건물 기본 공격은 별도 회귀 검사에 포함됩니다.
